# Raddish – Front-End Developer Portfolio

A personal front-end developer portfolio developed as part of **Portfolio 2 – Course Assignment** at **Noroff – School of Technology and Digital Media**.

The portfolio showcases selected projects from my front-end development studies, demonstrating my experience with React, TypeScript, JavaScript frameworks, CSS frameworks, responsive design, and accessibility.

The project builds upon my previous portfolio, maintaining the Raddish identity while improving the presentation, structure, and overall user experience.

## Installation 💻

To run the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/RaddishAI/portfolio2.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio2
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

The application will be available through the local URL provided by Vite.

### Production Build

```bash
npm run build
```

### ESLint

```bash
npm run lint
```
